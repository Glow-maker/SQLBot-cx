# 助手体验与问答页 UI 升级

日期：2026-09-08。范围由用户确认：动态助手预览页 + SQLBot 问答页。

## 设计依据

使用 `design-taste-frontend` 的审查、层级、颜色和形状一致性规则。该技能主要针对展示型页面，本次保留 Vue / Element Plus 产品界面，不引入营销式滚动、外部照片或新的构建体系。

设计参数：DESIGN_VARIANCE 4 / MOTION_INTENSITY 4 / VISUAL_DENSITY 4，Redesign-Preserve。保留 SQLBot 品牌蓝、已确认 Rocket 轮廓、Bloub、六种待机动作和真实业务状态契约。

## 改前审查与对应修改

| 观察 | 本次修改 |
| --- | --- |
| 预览页同时铺开形象、尺寸和动作，主次不清 | 单一主体验区 + 外观设置侧栏；尺寸检查折叠 |
| 原生选择器不能直观看出形象区别 | 静态形象选择按钮，选中态、开关与动作选择分组 |
| 角色与输入缺少互动关系 | 点击轻弹回应；输入聚焦时暂停待机花样、小幅看向输入区 |
| 欢迎页缺乏可操作的提问引导 | 趋势 / 对比 / 排名模板，仅填入草稿，不自动发送 |
| 欢迎区、输入区与浮层层级分散 | 聊天限定样式，统一间距、圆角、边框与焦点；保留历史和数据源入口 |

新增组件：`AssistantCompanion.vue`、`QuestionStarters.vue`。共享变量：`assistant-ui.css`。问答覆盖样式独立于原有业务逻辑：`views/chat/chat-refinement.css`。

## 验证记录

- 14 项助手测试通过。新增打招呼动作测试覆盖重复点击、输入聚焦、业务状态切换、换形象、关闭动画和卸载取消定时器。
- Vue 类型检查通过；以 `/sqlbot-app/` 和 `/api/v1` 构建生产前端通过。
- 独立预览实操：形象切换、动态开关、转圈试播、输入聚焦、清空、键盘焦点、深色与浅色、减少动态效果。关闭动画和减少动态效果时 `data-running=true` 数量均为 0。
- 实测 390px 与 320px 视口：主角色为 88px，文档宽度不超过视口；桌面为 112px，回答样例为 28px。临时设备与媒体模拟已还原。
- 同一浏览器保留 Rocket / 动态开启 / 自动换动作作为本轮检查结束状态。
- 已登录的本地问答页在重载前验证桌面欢迎布局和模板填入：草稿得到模板，回答行仍为 0，没有发送业务问题。
- 后续重载首屏出现空白。隔离浏览器检查观察到 `/api/v1/system/config/key` 返回 500，许可证初始化未完成。现有路由在这些初始化完成前不进入页面；未扩大范围修改后端配置。

## 预检与未验收项

- 一致性：预览整页随系统深浅主题切换，问答页继承宿主主题；圆角按容器 16、控件 10 分级；沿用品牌色；无装饰性跑马灯、虚构数据卡片或模拟成功文案。
- 可访问性：输入和开关有标签、按钮保留原生键盘行为、选择态可读、焦点可见；Escape 关闭外观浮层后回到入口；减少动态效果时无角色循环。静态角色不降低透明度。
- 既有角色 SVG 为用户已确认的真实功能素材；无需替换为图片生成素材。滚动监听仅用于指针坐标校准，保留其清理测试，不引入滚动叙事效果。
- Lighthouse 未运行（本项目未安装该工具）；不声称性能评分或完整可访问性审计通过。
- 问答页窄屏历史抽屉、qiankun 内嵌页及真实问数 / 分析 / 预测回归尚未完成。自动化业务测试使用流式夹具，不代表真实数据验收。
- 未部署、未重启后端、未更新旧发布 ZIP。当前改动与同工作区索引后端改造分别管理。
